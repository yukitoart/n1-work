# 視聴維持率を意識した構成テンプレート（10分前後）

## 前提
- 視聴者は最初の数秒〜30秒で「見続けるか」を決める。冒頭の離脱が最優先の改善ポイント。
- 中盤の離脱は「続きが気になる要素（オープンループ）」が切れたときに起きる。結論を一気に出し切らない。
- 冗長な説明・長い間・同じ画面の長回しはテンポを落とす。1〜2文ごとに画面を変える。
- 構成は仮説。公開後は YouTube Studio の維持率グラフで急落箇所を見て、次回の台本に反映する。

## 型（#001 サイゼリヤ回での実装）

| 時間 | ブロック | 役割 | #001 での中身 |
|---|---|---|---|
| 0:00–0:50 | **コールドオープン** | 矛盾の提示 → 意外な事実 → いま起きている危機 → 見る理由の約束 | 300円なのに儲かる？／利益の2/3は海外／値上げ検討／「この動画でわかること」3つ／最後まで見る理由（諸刃の剣） |
| 0:50 | タイトル | ここで初めてタイトル。挨拶やロゴは入れない | |
| 〜1:55 | 第1章 **物語** | 数字の前に人の話で感情を動かす（失敗→逆転） | 開業→火事→客が来ない→7割引きで逆転 |
| 〜3:30 | 第2・3章 **意外な数字** | 1つ目の「えっ」を出す。章の終わりで次の問いを投げる | 利益は日本よりアジア → 「なぜ潰れない？」 |
| 〜6:40 | 第4〜6章 **答え（3つ）** | 1章1答え。各章の終わりに「でも、これだけでは足りない」で次へつなぐ | 製造直販／店で料理しない／薄利×客数 |
| 〜7:45 | 第7章 **2つ目の「えっ」** | 中だるみ帯（6〜8分）に新しい驚きを置く | 日本の利益が2倍以上に |
| 〜9:10 | 第8章 **冒頭の約束の回収** | オープンループを閉じる。結論に葛藤を残す | 値上げは「諸刃の剣」 |
| 〜9:40 | まとめ＋次回予告 | 学びの整理と、次の動画へのループ | 「なぜアジアは儲かる？」 |
| 最後の14秒 | 終了画面 | 終了画面要素（次の動画・登録）用に空ける | |

## 毎回のチェックリスト
- [ ] 冒頭10秒以内に「矛盾」か「意外な数字」がある
- [ ] 冒頭で「この動画でわかること」と「最後まで見る理由」を約束している
- [ ] 章の終わりが次の問いで終わっている（「では、なぜ〜？」「でも、これだけでは〜」）
- [ ] 6〜8分あたりに新しい驚きがある
- [ ] 冒頭の約束を最後に必ず回収している
- [ ] 1カットは長くても10秒程度。インパクトテロップは1章に1〜2回まで（多すぎると効かない）

## テロップの使い分け
| 種類 | 使う場面 | 書き方（episode.json） |
|---|---|---|
| 字幕の強調（黄色＋マーカー） | 各行のキーワード1つ | `"text": "利益の[約3分の2]は…"` |
| インパクトテロップ（中央・効果音付き） | 章のいちばんの驚き | `"impact": "利益の[3分の2]は\n日本の外"` |
| 問いテロップ（左上 Q.） | 章の冒頭。いま何の話かを常に見せる | `"q": "なぜ潰れない？"` |
| 注記（字幕の上） | 報道ベースの情報 | `"note": "※ 報道による"` |
